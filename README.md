# 🧮 Calculadora de Taxas Ton

Um simulador de taxas para maquininhas da Ton, desenvolvido como projeto prático para consolidar os aprendizados dos **Módulos A ao D** do curso de **JavaScript** do canal Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

## 🚀 Sobre o Projeto

O objetivo principal deste projeto foi aplicar conceitos fundamentais de lógica de programação, matemática financeira e manipulação do DOM em um cenário do mundo real.

A aplicação permite calcular:

* Quanto será recebido após o desconto das taxas da maquininha;
* Quanto deve ser cobrado do cliente para receber um valor líquido desejado;
* Simulações para débito, crédito à vista e crédito parcelado;
* Diferenças entre bandeiras Visa/Mastercard e Elo/American Express.

Durante o desenvolvimento, o projeto foi utilizado como exercício para praticar programação sem dependência de frameworks ou bibliotecas externas, utilizando apenas HTML, CSS e JavaScript puro.

---

## 🧠 Conceitos Praticados (Módulos A ao D)

### Módulo A – Conhecendo a Web e o JavaScript

* Funcionamento básico do JavaScript na web;
* Configuração do ambiente de desenvolvimento com VS Code;
* Organização inicial de arquivos HTML, CSS e JavaScript.

### Módulo B – Comandos Básicos

* Criação e utilização de variáveis com `let` e `const`;
* Manipulação de tipos de dados (`String`, `Number`, `Boolean`);
* Conversão de tipos utilizando `Number()`;
* Formatação monetária com `toLocaleString()`.

### Módulo C – Entendendo o DOM

* Seleção de elementos HTML com `querySelector()`;
* Manipulação de eventos utilizando `addEventListener()`;
* Leitura de valores de inputs, selects e radio buttons;
* Alteração dinâmica do conteúdo da página através do JavaScript.

### Módulo D – Condições em JavaScript

* Utilização de estruturas condicionais (`if`, `else if` e `else`);
* Tomada de decisões baseada na forma de pagamento e bandeira selecionadas;
* Organização de regras de negócio utilizando lógica condicional.

### Matemática Financeira Aplicada

Durante o desenvolvimento foi necessário compreender a diferença entre:

* Cálculo direto de desconto de taxas;
* Cálculo reverso para descobrir quanto cobrar a fim de receber um valor líquido específico.

Essa lógica foi implementada utilizando:

* Multiplicação pelo fator líquido para descobrir quanto será recebido;
* Divisão pelo fator líquido para descobrir quanto deve ser cobrado.

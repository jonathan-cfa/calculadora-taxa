# 🧮 Calculadora de Taxas Ton

Um simulador de taxas para as maquininhas da Ton, desenvolvido como projeto prático para consolidar os aprendizados dos **Módulos A ao D** do curso de **JavaScript** do canal *Curso em Vídeo*, ministrado pelo professor Gustavo Guanabara.

## 🚀 Sobre o Projeto

O objetivo principal deste projeto foi aplicar os conceitos fundamentais de lógica de programação e manipulação do DOM em um cenário do mundo real. A aplicação simula o cálculo de quanto o vendedor recebe ou quanto o cliente paga ao passar um valor na maquininha, considerando diferentes planos da Ton (ex: GigaTon, UltraTon, MegaTon).

### 🧠 Conceitos Praticados (Módulos A ao D)

Este projeto foi construído do zero utilizando os seguintes pilares do curso:

* **Módulo A (Conhecendo a Web e o JS):** Entendimento de como o JavaScript funciona na engrenagem da web e configuração do ambiente de desenvolvimento (VS Code).
* **Módulo B (Comandos Básicos):** * Criação e uso de **Variáveis** (`let` e `const`).
    * Manipulação de **Tipos de Dados** (String, Number).
    * Conversão de tipos com `Number()` e formatação de moeda com `.toLocaleString('pt-BR', {style: 'currency', currency: 'BRL'})`.
* **Módulo C (Entendendo o DOM):**
    * Seleção de elementos HTML usando `document.getElementById()` e `document.querySelector()`.
    * Manipulação de eventos com `addEventListener` para capturar o clique do botão de calcular.
    * Alteração dinâmica do HTML/CSS para exibir os resultados na tela.
* **Módulo D (Condições):**
    * Uso de estruturas condicionais (`if`, `else if` e `else`) para aplicar a taxa correta dependendo da forma de pagamento selecionada (Débito, Crédito Vista ou Crédito Parcelado).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação da página e dos formulários de entrada.
* **CSS3:** Estilização e layout responsivo para simular um aplicativo real.
* **JavaScript (ES6):** Toda a lógica de cálculo e interatividade com o usuário.
